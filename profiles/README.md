# Instrument profiles / 音源预设

GP Bridge 不预装或默认指定任何音源预设。

从 [社区预设库 GP-Bridge-Presets](https://github.com/WTdusk/GP-Bridge-Presets) 选择与你的音源和版本相符的 JSON，将它放入 `GPBridgeData/Profiles/` 下，或在界面中选择它所在的文件夹。

社区预设库面向所有用户开放贡献。每个条目包含来源和验证状态，具体音源设置应查阅该条目的说明。也可以使用“创建预设”从官方手册提取配置，再人工核对。

Community instrument profiles are maintained separately. Download a matching profile and install it explicitly. No instrument is selected or bundled by default. Existing user profiles are preserved when upgrading.
