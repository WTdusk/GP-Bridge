# Kontakt Profiles

社区预设库：[WTdusk/GP-Bridge-Presets](https://github.com/WTdusk/GP-Bridge-Presets)。每个 JSON 文件对应一个明确的音色库/乐器预设。程序不内置任何音源映射；用户下载后安装到 `GPBridgeData/Profiles/`，或选择外部文件夹。请按照项目根目录的 `AGENT_KONTAKT_PROFILE_WORKFLOW.md` 从官方 Guide PDF 提取映射。

只有已记录来源、八度规则和验证状态的 profile 才应提交到这里。缺失或有歧义的技法必须写入 `ambiguities`，不能猜测。
