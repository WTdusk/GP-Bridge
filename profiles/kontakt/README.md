# Kontakt Profiles

独立预设库：[WTdusk/GP-Bridge-Presets](https://github.com/WTdusk/GP-Bridge-Presets)。每个 JSON 文件对应一个明确的 Kontakt 音色库/乐器预设。项目随版本打包的预设快照位于 `GPBridgeData/Profiles/kontakt/`。请按照项目根目录的 `AGENT_KONTAKT_PROFILE_WORKFLOW.md` 从官方 Guide PDF 提取映射。

只有已记录来源、八度规则和验证状态的 profile 才应提交到这里。缺失或有歧义的技法必须写入 `ambiguities`，不能猜测。
