# GP Bridge v0.1.1

开发者：**WTdusk**。

## 社区预设与主程序分离

- 新安装的程序不再附带或默认指定任何音源预设。
- 桌面界面新增“社区预设库”入口，空预设目录会提示下载或自行创建。
- 可以直接把克隆后的社区仓库设为预设目录，索引和模板不会作为乐器预设显示。
- 主仓库移除 Archtop 预设，测试改用独立的合成映射夹具。
- 构建脚本不再读取或打包本地用户预设；安装包只包含通用预设安装说明。
- [GP-Bridge-Presets](https://github.com/WTdusk/GP-Bridge-Presets) 作为面向所有用户的社区共享仓库，采用 CC0 1.0，支持通过 Pull Request 贡献不同音源的预设和验证记录。Archtop 作为其中的第一个条目维护。

## 使用方式

安装后点击“社区预设库”，选择适合自己音源和版本的 JSON，放入 `GPBridgeData/Profiles/`，或在程序中选择其所在目录。具体音源配置与验证状态请查阅社区条目。

升级时保留已有本地预设，不自动删除、更新或覆盖用户配置。

## 下载

- `GPBridge-Setup.exe`：Windows x64 安装包。
- `GPBridge-portable.zip`：解压后运行 GPBridge.exe。
- `SHA256SUMS.txt`：下载文件的 SHA-256 校验值。

转换引擎的已有格式支持和已知限制与 v0.1.0 相同：MIDI 采用单一速度，反复段落按书写顺序导出一次。无须安装 Python；运行音源仍需用户自行配置 DAW 和对应商业软件。
