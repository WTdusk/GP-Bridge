# GP Bridge v0.1.0

GP Bridge 的首个公开版本。开发者：**WTdusk**。

将 Guitar Pro GPX/GPIF 和 partwise MusicXML 转换为用于 Kontakt / VST 音源的 MIDI，包含中英双语桌面界面、命令行和 stdio MCP 服务。

## 下载

- **GPBridge-Setup.exe**：Windows x64 安装包。
- **GPBridge-portable.zip**：便携版，解压后运行 GPBridge.exe。
- **SHA256SUMS.txt**：以上文件的 SHA-256 校验值。

无需在目标电脑安装 Python。安装包和便携包均包含 MCP 服务、Archtop 预设、使用说明和第三方声明。

## 主要功能

- 读取 Guitar Pro 6 BCFZ/BCFS、Guitar Pro 7/8 ZIP 容器、GPIF/XML 和 partwise MusicXML。
- 保留来源乐器，支持按弦分轨、独立 MIDI Port 和分弦通道。
- 通过预设发出 Keyswitch、CC、Program Change、力度规则及组合技法事件。
- 可选自动延音和可调连奏/滑弦重叠；转换同时生成 JSON 报告。
- 从官方 PDF 通过配置的 Responses API 提取带证据的预设。
- 提供 list_presets、inspect_score、convert_score 三个 MCP 工具。
- 内置 Shreddage 3.5 Archtop 默认 TACT 预设；独立预设库：[GP-Bridge-Presets](https://github.com/WTdusk/GP-Bridge-Presets)。

## Archtop 配置

Kontakt 中开启 MIDI Guitar Mode，MIDI 输入设 OMNI；Vibrato 使用 CC1，Pitch Bend 范围设 ±2 半音。TACT Keyswitch 必须与预设一致。

## 验证与限制

- 本机 Windows / Python 3.12.14 下 48 项测试通过，GUI 初始化和打包后的 MCP 转换已验证。
- MIDI 使用单一速度，不保留完整变速图和拍号图；反复段落按书写顺序播放一次。
- Archtop 预设依据手册记录，尚未完成实际 Kontakt 播放验证。
- PDF 提取期间关闭窗口不会取消请求；建议等待提取结束。
- 尚未完成干净 Windows 系统的完整交互验证；本次提供 Windows x64 包。

本程序导出 MIDI，不生成音频，不包含 Kontakt 或商业音色库。详情及源码见 [主仓库](https://github.com/WTdusk/GP-Bridge)。
